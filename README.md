# 🤖 Browser-USE Bot

Bot con rotazione di 10 API Key per Browser-USE.

## 📋 Caratteristiche

- ✅ Rotazione automatica di 10 key (round-robin)
- ✅ Retry automatico con backoff
- ✅ Gestione errori (401, 403, 429, timeout)
- ✅ Statistiche in tempo reale
- ✅ Test automatico delle key all'avvio

## 🚀 Installazione

```bash
git clone <repository-url>
cd bot_repository
pip install -r requirements.txt
